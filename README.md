# AuGoField
Colour palette testing in common game scenes.

---
These are the represented semantic elements and their categories:

## Semantic Pawns
- Player Characters
- Non-Player Characters
- Enemies

## Semantic Props
- Collectables
- Interactables
- Static Props
- Decorative Props
- Dynamic Props

## Semantic Environments
- Environmental Terrain
- Suggestive Terrain (Visual Pathing cues)

## Input User Interfaces
- Buttons
- Sliders
- Toggles

## Feedback User Interfaces
- Informational Text
- Error Text
- Warning Text
- Status Indicators

---
# How to use
1. Choose a scene to load
2. Open the menu to affect the scene's colours and elements:
	a. Choose the colour of an element or an element category, colours can be chosen from a preset.
	b. Toggle the visibility of an elements on and off.
3. Capture a screenshot, or capture a 360 degree video.
